# Архив Северного района — v0.1

Статический прототип сайта вымышленного цифрового архива для проекта WHITEOUT.

## Уже есть

- главная страница электронного каталога;
- поиск и фильтрация по типам материалов;
- карточки фондов и статусы оцифровки;
- полностью сверстанный выпуск «Северного вестника» № 4 (1847) от 16.01.1999 — 4 страницы;
- просмотр страниц газеты стрелками или кнопками;
- отдельная оцифровка метеорологической сводки от 12.01.1999;
- адаптация каталога под телефон.

## Запуск

Можно просто открыть `index.html`.

Для GitHub Pages загрузите файлы в корень репозитория и включите `Settings → Pages → Deploy from a branch`.

## Важное по лору

Публичная версия пока нигде не использует название WHITEOUT и не объясняет происходящее. Первый выпуск специально выглядит почти обычным. Странности ограничены мелкими деталями, которые можно развить или заменить позже.
