# Архив Северного района — v0.2

Рабочий прототип сайта-архива для проекта WHITEOUT.

## Что изменилось в v0.2

- сайт получил более приглушённую серо-бежевую палитру и старомодный интерфейс;
- газета теперь выглядит как бумажная оцифровка, а не как современный HTML-текст;
- газетная полоса имеет фиксированный формат листа, плотную типографику, шум бумаги и слабые дефекты печати;
- добавлен масштаб просмотра 75 / 90 / 100 / 115%;
- добавлена типографская служебная строка внизу газетных полос;
- метеосводка стилизована как скан документа;
- аудиоматериал Р-18 теперь открывается как архивная карточка с текстовой расшифровкой;
- добавлен пока недоступный VHS-материал в каталог;
- в исходном HTML появились первые очень лёгкие служебные пометки для внимательных посетителей.

## Запуск

Открыть `index.html`.

Для локального HTTP-сервера:

```bash
python -m http.server 8000
```

Затем открыть:

```text
http://localhost:8000
```

## GitHub Pages

Все файлы должны лежать в корне ветки, используемой GitHub Pages.

Проект намеренно не содержит будущих сюжетных материалов: новые документы и подсказки лучше добавлять только в момент публикации, чтобы история Git не спойлерила сюжет.
